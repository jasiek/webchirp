Baofeng W31D programming software

Open WebCHIRP

WebCHIRP programs the Baofeng W31D in your browser. It runs the CHIRP project's own driver for this radio, so it reads and writes the same codeplug the desktop software does — without installing anything.

Program my W31D now

No driver install needed

Baofeng programming cables use a CH340, CP2102, PL2303 or FTDI USB-serial chip. WebCHIRP speaks to all four directly from the browser, so there is no driver package to download and no Windows version to match. Plug the cable in and pick the port when the browser asks.

What you can edit on the W31D

  • 30 memory channels, numbered 1 to 30
  • Channel names up to 6 characters
  • Transmit power: Low 0.5W, High 2.0W
  • Modes: FM, NFM
  • Bands: 400–480 MHz
  • Tone squelch: Cross, DTCS, TSQL, Tone

How to program a Baofeng W31D

  1. Plug the programming cable into the radio and the computer.
  2. Open WebCHIRP, check Baofeng W31D is selected, and press Download.
  3. Edit the channels, or pull in nearby repeaters from a directory.
  4. Press Upload to write the result back to the radio.

Questions

Do I need to install a USB driver to program the Baofeng W31D?

No. WebCHIRP talks to CH340, CP2102, PL2303 or FTDI programming cables from the browser, so there is nothing to install on Windows, macOS or Linux.

Do I need the Baofeng CPS software?

No. WebCHIRP runs CHIRP's own Baofeng W31D driver in the browser, so it reads and writes the same codeplug the desktop software does.

How many channels does the Baofeng W31D hold?

30, numbered 1 to 30 in the channel table.
