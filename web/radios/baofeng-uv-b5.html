Baofeng UV-B5 programming software

Open WebCHIRP

WebCHIRP programs the Baofeng UV-B5 in your browser. It runs the CHIRP project's own driver for this radio, so it reads and writes the same codeplug the desktop software does — without installing anything.

Program my UV-B5 now

No driver install needed

Baofeng programming cables use a CH340, CP2102, PL2303 or FTDI USB-serial chip. WebCHIRP speaks to all four directly from the browser, so there is no driver package to download and no Windows version to match. Plug the cable in and pick the port when the browser asks.

What you can edit on the UV-B5

  • 99 memory channels, numbered 1 to 99
  • Channel names up to 5 characters
  • Transmit power: Low 1.0W, High 5.0W
  • Modes: FM, NFM
  • Bands: 130–175 MHz, 220–269 MHz, 400–520 MHz
  • Tone squelch: Cross, DTCS, TSQL, Tone
  • Radio-wide settings, not just the channel list

How to program a Baofeng UV-B5

  1. Plug the programming cable into the radio and the computer.
  2. Open WebCHIRP, check Baofeng UV-B5 is selected, and press Download.
  3. Edit the channels, or pull in nearby repeaters from a directory.
  4. Press Upload to write the result back to the radio.

Questions

Do I need to install a USB driver to program the Baofeng UV-B5?

No. WebCHIRP talks to CH340, CP2102, PL2303 or FTDI programming cables from the browser, so there is nothing to install on Windows, macOS or Linux.

Do I need the Baofeng CPS software?

No. WebCHIRP runs CHIRP's own Baofeng UV-B5 driver in the browser, so it reads and writes the same codeplug the desktop software does.

How many channels does the Baofeng UV-B5 hold?

99, numbered 1 to 99 in the channel table.
