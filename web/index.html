    iPhone and iPad are not supported yet

    Every browser on iOS and iPadOS is built on Apple's WebKit engine, which offers neither Web Serial nor WebUSB — so installing Chrome, Edge or Firefox here will not help. Connect, Load from radio and Save to radio cannot work on this device today.

    We are working on a workaround so that iOS devices can talk to radios; until then, program your radio from a desktop or Android browser with Web Serial support.

    Everything file-based still works here: you can browse the radio catalog and edit channels from an imported CSV or binary codeplug.

    This browser cannot program radios

    WebCHIRP talks to radios through Web Serial, or WebUSB as a fallback, and this browser provides neither — so Connect, Load from radio and Save to radio will not work here.

    To program a radio, open this page in a browser with Web Serial support, such as Chrome, Edge, or a recent version of Firefox.

    Everything file-based still works: you can browse the radio catalog and edit channels from an imported CSV or binary codeplug.

    This browser cannot load radio drivers

    WebCHIRP runs CHIRP's radio drivers in your browser, which requires WebAssembly stack switching (JSPI). This browser does not support it, so drivers will fail to load and most of the app will not work.

    Recent versions of Firefox, Chrome and Edge all support it — if you are on an older Firefox, updating it also adds the Web Serial support needed to program radios.
