About WebCHIRP

Back to App

WebCHIRP is a browser-based customer programming software (CPS) which uses drivers developed by the excellent CHIRP project, made to run in a web browser. This has more or less the same functionality as CHIRP for the desktop.

Description for geeks follows. The core idea is running CHIRP's Python driver logic inside the browser through Pyodide (Python compiled to WebAssembly). A JavaScript bridge provides serial I/O to that Python runtime, so existing CHIRP radio protocol implementations can be reused instead of rewritten in JavaScript. Serial adapters on the desktop are handled by WebSerial, and on mobile we supply drivers for popular adapters via WebUSB (directly connecting to the USB device, without a kernel driver).

This project is still evolving, so expect rough edges and verify writes carefully, especially on first use with a particular model.

Source code: github.com/jasiek/webchirp
