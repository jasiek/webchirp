Checks a USB-serial adapter and the driver behind it by writing bytes and requiring them straight back. Bridge TX to RX on the adapter before running. To test the control lines as well, also bridge RTS to CTS and DTR to DSR.

This cannot verify baud rate. Both directions clock off the same divisor, so a wrong one still echoes perfectly — a pass means framing and buffering are sound, not that the line speed is accurate.

This browser exposes neither Web Serial nor WebUSB, so no adapter can be opened. Chrome, Edge and Opera on desktop support Web Serial; Chrome on Android supports WebUSB.
